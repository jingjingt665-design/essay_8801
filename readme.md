# 主题

基于机器学习与深度学习的新西兰区域月度旅游需求预测研究

## 写作目标

1、运用专业、法律以及伦理原则，调研特定研究领域的能力。需要基于近年已发表文献挖掘研究切入点，分析该研究领域现存待解决难题，并输出一份结构完整、图文观感良好、技术严谨的报告。分析近年文献所探讨的各类挑战，分析选题具备可行性、研究价值
2、写作要求
研究领域确定：已选定了一个计算机科学相关研究方向。需要结合统计数据、公开资料、近年论文阐述该领域的研究意义；梳理该主题的发展历史与演变过程。
研究主题梳理：梳理所选大领域下的主要研究主题、子方向。使用清晰表格或者示意图，展示主主题与子主题之间的关系。对每个主题进行简要阐述，包含核心概念、研究问题，说明主主题与子主题的关联。
选题收窄聚焦：从大领域进一步缩小范围，确定一个具体研究题目。需要综合考虑可行性、潜在研究价值，同时结合新西兰本土环境，或者毛利社群的实际场景。清晰说明选择该题目的理由。
挖掘研究机会：基于已经收窄的选题，找出潜在研究机会。研读近年文献，分析现有研究正在处理的各类难题；挖掘现有文献的研究空白、新兴趋势，找出值得进一步探索的方向。清晰论述这些研究机会如何推动本领域发展，以及它们对社会、技术以及其他行业可以带来的潜在影响。研究机会需要总结为现有文献呈现出的研究主题 / 研究趋势、研究路线。
